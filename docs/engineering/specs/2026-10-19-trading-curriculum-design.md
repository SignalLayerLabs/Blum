# Outcome-driven trading curriculum

BLUM's online memory is updating, but memory counts are not executable skill or forward profit. Add an explicitly experimental, persistent curriculum that selects among seeded BLUM adaptations of close-channel breakout, trend continuation, deviation reversion and pullback. Reuse the existing strategy evaluator and paper execution engine; do not add an unvalidated RL framework or promote strategies merely to create activity.

Each market/timeframe lane freezes a bounded, quality-checked source pack and chronological train/development/confirmation partitions. Random training episodes are non-overlapping blocks sampled without replacement; preceding bars are context only. Completed expert trades train a regularized contextual net-R predictor. Checkpoint identity includes the catalogue, source, costs and model. Development windows remain fixed across checkpoints; confirmation is reserved and never opened by the automatic worker. Repeated development scores are monitoring, not independent evidence or an unbiased final test.

Use a chronological, single-position, cash-constrained account per episode. Orders, risk and geometry are frozen from closed bars. Entry uses a bounded limit order on a later bar; cancellation, partial fills, adverse fills, commission, stop gaps and ambiguous stop/target ordering are explicit. No leverage, no short borrow assumptions, no fabricated OTC volume. Forex uses an explicitly declared research quote-capacity scenario and quote-currency returns, separately from verified broker execution and EUR cash. Missing trustworthy bars block the lane. Daily equity bars are available after New York close; intraday bars after interval close plus a fixed publication lag. Execution has one-bar reaction latency where close availability crosses the next bar's start.

The same frozen proposal/execution path records prospective paper practice: checkpoint, input hash and wall-clock decision precede all fill bars; later worker slices resolve the outcome. This research journal cannot enter the native/qualified paper P&L or make replay outcomes appear live. Every checkpoint reports trade count, Wilson win-rate interval, net return, drawdown, profit factor, expectancy and comparisons with cash, fixed seeded expert and same-asset price-only buy-and-hold. No win-rate guarantee, automatic promotion or real-money routing.

Worker slices are bounded and restart-safe. Public reads return stored results; writes retain existing admin protection. New curriculum tables use a normal migration. The worker runs within the existing bounded replay cadence. The research UI exposes progress and limitations. Existing frozen historical records are not rewritten.
